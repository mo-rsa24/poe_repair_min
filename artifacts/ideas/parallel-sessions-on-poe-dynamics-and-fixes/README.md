# Parallel sessions on PoE dynamics and fixes

One file: [the session sheet](SESSIONS.md). It lists eight Claude sessions that can run side by
side, each designing, planning and executing one experiment from the 2026-09-05 review of the
Diffusion Tree Sampling post, the Feynman-Kac steering paper, the Jaderberg post and the
optimal-transport post, plus the "correct early, then clean up" question. Each session carries a
pasteable prompt, what it produces, which scope it lands in, and what it waits on. Beside it,
[the pending-sync list](PENDING_SYNC.md) collects the edits to shared plan-tree files that the
sessions must not make concurrently, for one `/sync-plan-tree` run at the end.
