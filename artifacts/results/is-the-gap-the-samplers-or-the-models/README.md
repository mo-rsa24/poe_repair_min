# Is the gap the sampler's or the model's?

Pictures that ask whether a better sampler, one that adds no correction to the score, can reach
the composed image that product-of-experts sampling misses. The scope behind them is
[the sampler-versus-model scope](../../../plans/06-is-the-gap-the-samplers-or-the-models/MASTER_PLAN.md).
Every picture here is read in plain words, one section each, in [the figure explainer](figure-explainer.md).
