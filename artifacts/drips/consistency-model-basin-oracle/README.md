# The consistency-model basin oracle: the walk's working files

Working folder for the drip-walkthrough that judged the proposal to use LCM-SDXL as a basin
oracle on the cached PoE trajectories, under the diffusion-researcher role. The walk is finished:
it compiled on 2026-08-29 and its route out was taken, so nothing here is live.

## the-walk.md

The walk's full record: six layers of questions and the marks each one earned, the vocabulary the
role fixed along the way, and the pinned facts it worked from (epsilon prediction, DDIM at 50
steps, guidance 7.5, one cached `latent_trajectory.pt` per pair-and-seed cell as a deterministic
discretization of the probability flow ODE). The two claimed reads it was asked to judge were
committed-looking destination frames at high noise, and a per-step commitment probe.

**Where its output went.** The compiled decision ledger was adopted by the scope built from it,
[the commitment probe scope](../../../plans/05-when-does-the-outcome-lock-in/MASTER_PLAN.md),
as that scope's `decisions-taken-here.md`, which is the authoritative copy. This file is the
walk's own record and is kept because it carries the question rounds the ledger compresses away.
