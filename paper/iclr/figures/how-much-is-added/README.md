# How much is added

Both images are staged in the walk's Extras, not in the main text. They drop into the
manuscript as a unit with their paragraph on supervisor approval, per the Extras section of

**strength-grid-with-three-controls-and-compose-curve.png**. Cat and dog, one column per
lambda from 0 to 1. Top row injects the real correction and the fusion separates into two
animals as lambda rises. The three control rows inject the wrong pair's correction, the same
pair's correction from a wrong seed, and the same correction in the wrong order, and all three
stay a single animal. Below, the compose-rate curve for all four rows, counts by the detector.

**strength-grid-with-detector-boxes.png**. The same grid with each kept detection drawn as a
box, legend "box = one kept detection; compose needs two". This is the image that shows what
the counting actually is, an off-the-shelf object detector counting animals, manually verified.
