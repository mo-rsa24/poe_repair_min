# plans/phases/ — archived phase files

These are the original phase-numbered plan files (01–16), the `LORA_TAXONOMY_PLAN.md`
orchestrator, the retired `PHASE_MAP.md` master, and the Plan-12 runbook. They were
archived here on 2026-07-21 when the rung-based plan files `plans/01-05` became the
canonical work breakdown (see `/MASTER_PLAN.md`).

They are kept as **detailed reference**: each rung plan (`plans/0N-*.md`) folds one or
more of these and links back to them. Their mutual links are intact (they moved together);
outbound links to the repo root / `docs/` / `poe_repair/` are one directory level shallower
than written (add a `../`). This is archived reference material — not walked as live plans.

Start from `PHASE_MAP.md` for the original eight-phase narrative.
