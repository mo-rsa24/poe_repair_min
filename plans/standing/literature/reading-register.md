# The reading register

One row per paper read for this project. Every claim cited in `paper/iclr/iclr2027_conference.tex`
must trace to a row here; a claim needing a source that isn't below gets the `/paper-scout` cue in
the draft-section round, not a guess.

Each row's arXiv id and author list is checked directly against the arXiv abstract page, not
carried from memory or recall. "Read" states honestly how deep that check went: an abstract-level
check confirms the paper exists and says roughly what it's cited for; a deep read (marked where an
earlier session did one) is what backs a specific number, lemma, or mechanism claim.
